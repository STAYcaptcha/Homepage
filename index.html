STAYcaptcha
由 Wisnovate 设计的动作式质询 CAPTCHA（人机身份验证）组件，可自定义显示内容。

两种交互方式

方式一：长按验证

长按「按住」按钮5秒钟，进度条满后自动完成验证，无需其他操作。

方式二：可访问性挑战

按下「可访问性挑战」按钮5秒后，出现"再次按下"提示，点击按住按钮即可完成验证。

🚀 部署教程
1 引入 SDK
在 HTML 文件的 <head> 或 <body> 底部添加以下脚本： 
<script src="https://staycaptcha.github.io/Captcha/stay-captcha.js"></script>
2 放置容器
在页面中需要显示验证组件的位置，添加一个容器元素： 
<div id="captcha-container"></div>
3 初始化验证器
调用 STAYcaptcha.init()： 
<script>
  STAYcaptcha.init({
    container: '#captcha-container',
    onSuccess: function() {
      // ✅ 验证通过
    },
    onFail: function() {
      // ❌ 验证失败
    }
  });
</script>
💡 组件内部的文字由 SDK 自带，你只需要在 onSuccess 里写验证通过后的逻辑。
📦 完整示例
将以下代码复制到 HTML 文件中即可运行： 
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>STAYcaptcha 示例</title>
</head>
<body>

    <div id="captcha-container"></div>

    <script src="https://staycaptcha.github.io/Captcha/stay-captcha.js"></script>
    <script>
        STAYcaptcha.init({
            container: '#captcha-container',
            onSuccess: function() {
                alert('✅ 人机验证通过！');
            },
            onFail: function() {
                alert('❌ 验证失败，请重试');
            }
        });
    </script>

</body>
</html>
