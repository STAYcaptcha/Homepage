两种交互方式

方式一：长按验证

长按「按住」按钮5秒钟，进度条满后自动完成验证，无需其他操作。

方式二：可访问性挑战

按下「可访问性挑战」按钮5秒后，出现"再次按下"提示，点击按住按钮即可完成验证。

部署教程一：添加人机验证小组件
1 引入 SDK
在 HTML 文件的 <head> 或 <body> 底部添加以下脚本： 
<script src="https://staycaptcha.github.io/Captcha/stay-captcha.js"></script>
2 放置容器
在页面中需要显示验证组件的位置，添加一个容器元素： 
<div id="captcha-container"></div>
3 初始化验证器
调用 STAYcaptcha.init()： 
<script>
  STAYcaptcha.init({
    container: '#captcha-container',
    onSuccess: function() {
      // 验证通过
    },
    onFail: function() {
      // 验证失败
    }
  });
</script>
组件内部的文字由 SDK 自带，你只需要在 onSuccess 里写验证通过后的逻辑。
4 完整示例
将以下代码复制到 HTML 文件中即可运行： 
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>STAYcaptcha 示例</title>
</head>
<body>

    <div id="captcha-container"></div>

    <script src="https://staycaptcha.github.io/Captcha/stay-captcha.js"></script>
    <script>
        STAYcaptcha.init({
            container: '#captcha-container',
            onSuccess: function() {
                alert('人机验证通过！');
            },
            onFail: function() {
                alert('验证失败，请重试');
            }
        });
    </script>

</body>
</html>
部署教程二：添加网页安全验证页
1 引入 SDK
在 HTML 文件的 <head> 或 <body> 底部添加以下脚本： 
<script src="https://staycaptcha.github.io/One-more-step/One%20more%20step.js"></script>
此 SDK 会自动全屏显示人机验证遮罩层，验证通过后页面内容才会显示。
2 验证成功后自动关闭
用户完成人机验证后，点击 Submit 按钮即可关闭遮罩层，正常访问网站。
如果未完成验证点击 Submit，验证框外围会显示红色边框提示。
3 完整示例
将以下代码复制到 HTML 文件中即可运行： 
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>我的网站</title>
</head>
<body>

    <h1>网站内容</h1>
    <p>验证通过后才能看到我</p>

    <script src="https://staycaptcha.github.io/One-more-step/One%20more%20step.js"></script>
</body>
</html>
引入 SDK 后，用户打开页面会先看到安全验证页，验证通过后才能浏览网站内容。
4 功能特性
  • ✅ 全屏遮罩，验证通过前阻止访问
  • ✅ 显示当前网站域名
  • ✅ 验证成功后点击 Submit 关闭
  • ✅ 验证失败时红色边框提示
  • ✅ 禁止右键、复制、选中文字
  • ✅ 完全免费，开箱即用
